# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to **dev.rarione@pm.me**.

Where applicable, include:

- The affected player version, experiment, package, or repository component.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Relevant technical details or supporting evidence.

Please avoid including credentials, personal information, or other sensitive data unnecessarily.

## Scope

Security reports may concern the official Lab Player, package handling, repository contents, or officially distributed experiments.

Independent forks, modified builds, and third-party distributions are outside the scope of this policy.

## Responsible Disclosure

Please avoid publicly disclosing unresolved vulnerabilities through GitHub Issues, Discussions, or pull requests.

Do not access, modify, or disclose data belonging to others without authorization.

## Maintenance

RariWare Lab is an independent creative and educational project. Security reports are evaluated individually. No response time, remediation timeline, or continued maintenance is guaranteed.

Ordinary bugs, compatibility issues, and creative suggestions may be submitted through GitHub Issues.
