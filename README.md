# RariWare Lab

**No roadmap. Just because.**

RariWare Lab is a place for small programs, text art, animations, and curious experiments made for the enjoyment of making them.

Some pieces are quiet. Some move. Some are useful for absolutely nothing. That's fine.

Python, ASCII, and Unicode are recurring materials here, not the limits of what can be explored. An experiment can be a few lines long or an elaborate standalone program. It doesn't need to become a product, solve a problem, or fit a theme.

[Lab Player](player/README.md) plays local artwork on Windows and Linux (x64) and lets you browse the source behind each piece.

## Explore

Each experiment belongs in its own directory and should include a short explanation of what it does and how to run it. Some experiments may also include exported artwork suitable for display elsewhere.

Not everything here needs to be exhibited. The experiments themselves are the point.

## Make something

Read the [Creative Standard](CREATIVE-STANDARD.md) for how to make and share an experiment. The [contribution guide](CONTRIBUTING.md) explains how to submit it, how review works, and what permissions are needed for official publication.
