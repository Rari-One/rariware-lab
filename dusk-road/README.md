# Dusk Road

A road home through the woods at dusk. Pines slide past on either side,
fireflies drift over the grass, mist lies low over the road, and a small
warm light waits on the horizon under a low moon.

Silent. 120 × 40, 15 fps, 180 frames (12 s loop).

## Regenerate

Python 3.10+, standard library only. From the repository root:

```sh
cd dusk-road
python dusk-road.py --export --package
```

`--export` writes the gallery `frames.json` and `manifest.json`;
`--package` writes the playable `dusk-road.rwl` for the Lab Player.
